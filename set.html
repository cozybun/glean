How to Play 🃏

Each card has 4 features:

Shape: Bun, Snake, or Wolf
Color: Red, Green, or Blue
Shading: Solid, Striped, or Outline
Number: 1, 2, or 3

Select 3 cards. For each feature, all 3 cards must be either all the same or all different.

✅ Valid Set!
Same shape, number, & shading. Different colors.

New cards replace completed Sets.
Find all possible Sets to win.
Time & mistakes are tracked. Have fun! 😊

Select 3 cards to find a Set! 🃏
